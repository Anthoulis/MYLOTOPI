# Mylotopi QR Guide

Στατικός, πολύγλωσσος οδηγός επίσκεψης για το Μυλοτόπι στην Κέφαλο της Κω.
Μία δημόσια είσοδος μέσω QR, 9 στάσεις, κείμενο και ήχος σε 10 γλώσσες.
Η σχεδίαση δίνει προτεραιότητα στη χρήση από κινητό στον χώρο της επίσκεψης.

## Πώς είναι φτιαγμένο

Κάθε γλώσσα είναι μία έτοιμη σελίδα HTML (`en/index.html` … `tr/index.html`), που
παράγεται από το περιεχόμενο με `npm run build` και μπαίνει στο git όπως είναι.
Ο server απλώς σερβίρει αρχεία· τίποτα δεν χτίζεται πάνω του. Το κείμενο φαίνεται
αμέσως, και διαβάζεται ακόμη και χωρίς JavaScript. Η λίγη JavaScript που τρέχει
στο κινητό κάνει μόνο τα ζωντανά κομμάτια: τον player, τη στάση που φαίνεται και
τον χάρτη.

| Διαδρομή | Ρόλος |
| --- | --- |
| `assets/content/<lang>.json` | Το κείμενο κάθε γλώσσας: UI και 9 στάσεις. Εδώ αλλάζουν τα κείμενα. |
| `assets/content/meta.json` | Γλώσσες, aliases, σειρά στάσεων, φωτογραφίες και χρώμα κάθε στάσης. |
| `scripts/site.mjs` | Φτιάχνει το HTML κάθε σελίδας από το περιεχόμενο (καθαρές συναρτήσεις). |
| `scripts/media.mjs` | Διαβάζει διαστάσεις εικόνων και διάρκεια MP3 από τα ίδια τα αρχεία. |
| `scripts/build.mjs` | Γράφει τις σελίδες· με `--check` ελέγχει ότι είναι ενημερωμένες. |
| `scripts/validate-content.mjs` | Έλεγχος δομής περιεχομένου και αναφορών assets. |
| `en/` … `tr/`, `index.html`, `qr-guide.html`, `assets/css/stops.css` | Ό,τι παράγεται: οι σελίδες, και τα χρώματα και οι θέσεις φωτογραφιών κάθε στάσης. Δεν τα αλλάζουμε με το χέρι. |
| `assets/js/guide.js` | Ο player, η στάση που φαίνεται, τα μενού, ο χάρτης, οι φωτογραφίες. |
| `assets/js/entry.js`, `assets/js/language.mjs` | Η είσοδος: στέλνει κάθε παλιά και νέα διεύθυνση στη σωστή γλώσσα. |
| `assets/css/main.css` | Εμφάνιση, responsive layout και προσβασιμότητα. |
| `assets/audio/<lang>/`, `assets/maps/`, `assets/images/stops/` | Ήχος, χάρτες και φωτογραφίες. |
| `test/runtime.test.mjs` | Αυτοματοποιημένοι έλεγχοι. |
| `tools/deploy.sh` | Ανέβασμα στο `mylotopi.varon.gr`. |

## Αλλαγή κειμένου

1. Αλλάζεις το `assets/content/<lang>.json`.
2. `npm run build`.
3. `npm run check`.

Αν ξεχαστεί το βήμα 2, το `npm run check` αποτυγχάνει και λέει ποια σελίδα είναι παλιά.

## Τοπική εκτέλεση και έλεγχοι

Οι σελίδες ανοίγουν από οποιονδήποτε στατικό HTTP server, στη ρίζα του repository.
Το διπλό κλικ σε αρχείο HTML δεν είναι αξιόπιστος τρόπος δοκιμής, γιατί οι
σύνδεσμοι και τα modules της JavaScript θέλουν κανονική διεύθυνση.

Οι έλεγχοι χρειάζονται Node.js με υποστήριξη του `node --test` και npm.
Το `package.json` δεν ορίζει εξωτερικές εξαρτήσεις. Δεν προσθέτουμε εξαρτήσεις.

```sh
npm run check
git diff --check
```

Το `npm run check` εκτελεί τον έλεγχο περιεχομένου, ελέγχει ότι οι σελίδες είναι
ενημερωμένες και τρέχει τα tests. Δεν υποκαθιστά την επιθεώρηση σε browser ή την
ακρόαση των αρχείων ήχου.

## Πού είναι online

| Διεύθυνση | Κλάδος | Ρόλος |
| --- | --- | --- |
| `mylotopi.netlify.app` | `production` | Αυτό που χρησιμοποιεί η επιχείρηση, ως το τέλος της σεζόν. |
| `mylotopi.varon.gr` | `develop` | Η νέα έκδοση, για δοκιμή, στον server της varon. Εκτός μηχανών αναζήτησης. |

Το `mylotopi.varon.gr` ανεβαίνει με `bash tools/deploy.sh`, μόνο από commit και μόνο
όταν ζητηθεί ρητά. Ο Caddy του ρυθμίζεται από το repository της varon
(`server/caddy/sites/mylotopi.caddy`).
