# Mylotopi QR Guide

Στατικός, πολύγλωσσος οδηγός επίσκεψης για το Μυλοτόπι στην Κέφαλο της Κω.
Μία σελίδα, μία δημόσια είσοδος μέσω QR, 9 στάσεις, κείμενο και ήχος σε 10 γλώσσες.
Η σχεδίαση δίνει προτεραιότητα στη χρήση από κινητό στον χώρο της επίσκεψης.

## Πού βρίσκονται οι οδηγίες

ανάγνωσης, όχι δεύτερο αντίγραφο όλων των κανόνων.

## Τοπική εκτέλεση και έλεγχοι

Δεν υπάρχει framework, build βήμα ή runtime backend. Η σελίδα φορτώνει JSON με
`fetch`, επομένως χρειάζεται στατικό HTTP server και άνοιγμα του `/index.html`.
Το διπλό κλικ σε αρχείο HTML δεν αποτελεί αξιόπιστο τρόπο δοκιμής.
Το repository δεν παρέχει σήμερα `npm start` ή δικό του HTTP server.

Οι έλεγχοι χρειάζονται Node.js με υποστήριξη του `node --test` και npm.
Το `package.json` δεν ορίζει εξωτερικές εξαρτήσεις ούτε συγκεκριμένη ελάχιστη
έκδοση Node. Δεν προσθέτουμε εξαρτήσεις μόνο για να τρέξουν οι υπάρχοντες έλεγχοι.

```sh
npm run check
git diff --check
```

Το `npm run check` εκτελεί `npm run validate` και `npm test`.
Δεν υποκαθιστά την επιθεώρηση σε browser ή την ακρόαση των αρχείων ήχου.
