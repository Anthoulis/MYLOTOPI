# Source Texts

This folder stores temporary source documents used to build runtime JSON content.

Runtime visitor text must live in `assets/content/<language>.json`. Do not link files from this folder in the public guide.

- `bullet-points/`: source Word files imported into the matching language JSON files. Filenames use runtime language codes.
- `instructions.docx`: internal source notes moved out of `assets/content` so the runtime content folder stays JSON-only.
