# Print Asset Folder

These files are source and reference print assets for the Mylotopi QR Guide visitor flow.

Print assets are not automatically public.

Keep filenames stable where possible so final replacements do not require documentation or link changes.

Visitor-facing source assets copied from the Mylotopi source folder:

- `mini-map.jpg`
- `mini-map.pdf`
- `mylotopi-sketch.jpg`
- `mylotopi-sketch.pdf`

Legacy draft filenames may remain for reference, but public runtime mini-map images are served from `assets/maps/<lang>/minimap.jpg`.

`staff-instructions.docx` must not be linked from the public UI.

Visitor-facing print files can later be linked only if explicitly approved.
